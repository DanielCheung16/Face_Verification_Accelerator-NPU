\section{Conclusions}
\label{sec:conclusion}

We delivered a hybrid CNN accelerator for MobileFaceNet inference, implemented along two complementary tracks (Zynq UltraScale+ FPGA and FreePDK45 ASIC) from a single INT8 RTL source. Both tracks were verified against the same C-model golden reference. The deliverables map directly onto the four headline outcomes:

\begin{itemize}[nosep]
\item Designed a hybrid CNN accelerator for MobileFaceNet inference using a $14\times16$ systolic array, a $3\times3$ standard array, and a $7\times7$ depthwise engine, all behind a single Switcher.
\item Supported dynamically sized $1\times1$, $3\times3$, and depthwise convolution operators with INT8 (w8a8) quantisation, PReLU, and residual addition.
\item NPU runs at 150\,MHz on FPGA ($\times7.18$ over an i7-9700 baseline) and 200\,MHz on ASIC ($\times9.57$).
\item Passes both FPGA on-board verification and Innovus SDF-annotated post-route gate-level verification.
\end{itemize}

\paragraph{Did the design meet spec?} Yes for the ASIC track. All hard constraints were met and both soft constraints (power, area) cleared with margin. The FPGA track meets the same functional requirements and reaches 7.82\,FPS at 150\,MHz; a higher-grade RFSoC-class part would scale this proportionally.

\paragraph{What was not delivered.}
\begin{itemize}[nosep]
\item No tape-out: the ASIC is design-kit only.
\item No formal LEC: we used full GL simulation instead.
\item Single typical-PVT corner; no SI / cross-talk analysis.
\item The FPGA bitstream targets a development board, not a productised platform.
\end{itemize}

\paragraph{Lessons learned.} Verification took longer than RTL design. Two specific items dominated the schedule: the gate-level testbench race that required \texttt{bind}-based probes to localise (Section~\ref{sec:opt:asic}), and the OpenRAM LEF patching needed to clean up DRC. Both would have been easier with deterministic instrumentation in place from day one.
