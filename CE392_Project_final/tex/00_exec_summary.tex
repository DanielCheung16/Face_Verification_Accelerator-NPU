\section*{Executive Summary}
\addcontentsline{toc}{section}{Executive Summary}

\paragraph{Problem.} Edge face verification needs a 50-layer CNN to run under $\sim$100\,mW at real-time frame rates. General-purpose CPUs and GPUs are too power-hungry to fit that envelope.

\paragraph{Approach.} We designed a hybrid INT8 CNN accelerator specialised for MobileFaceNet. The compute fabric combines a $14\times16$ systolic array for the $1\times1$ convolutions that dominate the workload, a $3\times3$ standard array for $3\times3$ convolutions and $3\times3$ depthwise convolutions, and a dedicated $7\times7$ depthwise engine. The same RTL is brought up along two complementary tracks: a Zynq UltraScale+ FPGA bitstream for hardware-in-the-loop verification, and a FreePDK45 Innovus place-and-route flow for ASIC area, power, and timing data.

\paragraph{Key Results.}
\begin{itemize}[nosep]
\item \textbf{FPGA (Zynq UltraScale+)}: 150\,MHz, 19.18\,M cycles per inference, 127.8\,ms per image, $\times7.18$ over an i7-9700 baseline. Resource utilisation 25\,\% LUT, 20\,\% FF, 54\,\% BRAM, 10\,\% DSP.
\item \textbf{ASIC (FreePDK45)}: 200\,MHz, 19.18\,M cycles per inference, 95.88\,ms per image, $\times9.57$ over the same i7-9700 baseline. Core area 720$\times$720\,$\mu$m$^2$, total power 96.32\,mW, energy 9.24\,$\mu$J per inference, DRC/connectivity/antenna 0.
\item \textbf{Functional verification}: bit-exact 50/50 layer match against the C-model at RTL, post-syn netlist, post-route netlist, and SDF-annotated post-route gate level (zero timing violations).
\item \textbf{Model accuracy}: hardware-spec fixed-point matches the QuantFace INT8 reference within 0.20\,\% on LFW and $-0.12\,\%$ on AgeDB-30, both inside the protocol's statistical error.
\end{itemize}

\paragraph{Limitations.}
\begin{itemize}[nosep]
\item No commercial formal LEC tool was available; equivalence is shown by full 50-layer gate-level simulation rather than mathematical proof.
\item Single-corner timing signoff (typical PVT only); no SI/CRPR analysis.
\item ASIC track is design-kit physical implementation only, not taped out. The FPGA bitstream targets a development board, not a productised platform.
\end{itemize}
