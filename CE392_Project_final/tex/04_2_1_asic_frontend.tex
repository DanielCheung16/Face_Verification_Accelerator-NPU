\paragraph{Compute datapath.} The core compute unit is \texttt{mfn\_sa\_12x12}, a $12\times12 = 144$ processing-element (PE) output-stationary systolic array. Each PE \texttt{mfn\_pe} holds one output channel's 40-bit accumulator and performs a single signed $16\times16 \rightarrow 32$-bit multiply followed by a sign-extended add per cycle. The array supports two dataflow modes selected by \texttt{dw\_mode}:
\begin{itemize}[nosep]
\item \textbf{Pointwise / standard mode} (\texttt{dw\_mode=0}): each row computes the 12-tap dot product $\sum_{c=0}^{11}\texttt{act\_in}[c]\cdot\texttt{wgt\_in}[r][c]$. All 144 MACs fire per cycle, parallel across 12 output channels and 12 input channels.
\item \textbf{Depthwise mode} (\texttt{dw\_mode=1}): each row uses its own activation lane (diagonal mapping) since depthwise convolutions never mix channels. The array degrades to 12 independent MACs per cycle, mirroring the natural parallelism of the operation.
\end{itemize}
A pipeline register (\texttt{row\_dot\_reg}, 12$\times$40-bit) between the multiplier-adder tree and the final accumulator update splits the critical path, enabling the 5.0\,ns / 200\,MHz target.

\paragraph{Memory hierarchy.} Three classes of on-chip storage are used:

The choice between SRAM and ROM is driven by access pattern and size: large random-access read/write storage uses SRAM; small read-only constants synthesise more cheaply as gates.

\paragraph{Controller FSM.} \texttt{mfn\_controller\_v3} is a 25-state machine partitioned into three sub-paths, one per convolution mode:
\begin{itemize}[nosep]
\item Pointwise / standard path (\texttt{S\_ACT\_LOAD} $\rightarrow$ \texttt{S\_BIAS\_LOAD} $\rightarrow$ \texttt{S\_CIN\_COMPUTE} $\rightarrow$ \texttt{S\_WRITEBACK}),
\item Depthwise path (\texttt{S\_DW\_FETCH} $\rightarrow$ \texttt{S\_DW\_COMPUTE} $\rightarrow$ \texttt{S\_DW\_DRAIN} $\rightarrow$ \texttt{S\_DW\_WRITEBACK}),
\item Depthwise-12 fast path for layers whose channel count is a multiple of 12 (\texttt{S\_DW12\_BIAS} $\rightarrow$ \texttt{S\_DW12\_COMPUTE} $\rightarrow$ \texttt{S\_DW12\_KP\_NEXT}).
\end{itemize}
All address generation, SA enable/clear, and SRAM write enables are driven directly from the FSM; there is no host intervention between layers.
