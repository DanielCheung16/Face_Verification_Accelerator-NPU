\subsection{Process and IP Availability}
The FreePDK45 educational PDK provides only standard-cell timing and LEF/Liberty data; no foundry SRAM compiler is included. We therefore generated all on-chip SRAM macros via the OpenRAM open-source SRAM compiler, which produces synthesizable behavioural models for simulation and LEF/Liberty/GDS views for physical implementation. This constraint shaped the memory subsystem: we use only two SRAM macros (activation buffer and partial-sum buffer) and keep small constant storage (weights, biases, PReLU $\alpha$, layer configuration) as combinational ROMs that the synthesizer maps to standard-cell mux trees.

\subsection{Verification Capability}
The lab environment does not provide a commercial formal-equivalence checker (Conformal LEC / Formality), nor signal-integrity-aware static timing (PrimeTime SI). We therefore replace formal LEC with full 50-layer gate-level simulation against the C-model golden vectors, and replace SI timing with SDF-annotated gate-level simulation using the Innovus-extracted SDF. These substitutions are slower than the commercial flows (a single full SDF run takes several days) but provide functionally equivalent coverage for non-tape-out signoff.
